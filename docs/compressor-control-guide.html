작업반장 판단

지금 가진 리모컨은 아주 도움이 된다. 콤프레셔 내부 220V 전원을 뜯지 말고, 리모컨 버튼을 ESP32가 대신 눌러주는 방식으로 가자.

압력 조절은 산업용 전공 레귤레이터가 맡고, ESP32는 목표압 지시, 실제압 확인, 앱 통신, 기록만 담당한다.

완성 목표

태블릿 앱에서 콤프레셔 ON/OFF, 목표압 입력, 실시간 압력 표시, 누수검사용 압력 하락 그래프 저장.

1. 먼저 결론

초보자가 직접 만질 구간은 리모컨 버튼 접점, ESP32, 센서, 24V DC 저전압 배선까지만이다. 콤프레셔 모터 전원, 220V 배선, 탱크 안전밸브, 압력스위치는 건드리지 않는다.

4. 리모컨 납땜 작업

리모컨은 콤프레셔를 직접 제어하지 않고 이미 설치된 수신기에 명령만 보낸다. 우리는 버튼 양끝에 선을 붙여서 ESP32가 대신 누르게 만든다.

  1. 리모컨 배터리를 뺀다.
  2. 리모컨을 열고 ON 버튼 양쪽 패드를 찾는다. 멀티미터 도통 모드로 버튼을 누르면 서로 연결되는 두 점이 정답이다.
  3. 그 두 점에 얇은 선 2가닥을 납땜한다. 선 끝은 릴레이 CH1의 COM/NO에 연결한다.
  4. OFF 버튼도 같은 방법으로 CH2의 COM/NO에 연결한다.
  5. ESP32는 릴레이 입력핀만 제어한다. 버튼 접점과 ESP32 전원을 직접 섞지 않는다.
테스트 방법: ESP32 없이 릴레이 COM/NO 대신 선 두 가닥을 0.5초만 서로 대보면 버튼을 누른 것처럼 동작해야 한다. 이때 콤프레셔가 정상 반응하면 리모컨 접점 찾기는 성공이다.

6. 압력센서 연결

0.5-4.5V 압력센서를 쓸 경우 ESP32 입력은 3.3V까지만 안전하므로 전압분배 또는 ADC 모듈을 사용한다.

압력 계산식 예시: 센서 원래 전압이 0.5V일 때 0bar, 4.5V일 때 10bar라면, bar = (전압 - 0.5) / 4.0 * 10 이다. 전압분배를 쓰면 코드에서 원래 전압으로 환산해야 한다.

7. 실행 순서

  1. 1일차: 리모컨 자동 누름부터 성공
    리모컨 ON/OFF 버튼 접점을 찾아 릴레이에 연결한다. 앱 없이 수동 테스트로 버튼 동작 확인.
  2. 2일차: ESP32가 리모컨을 누르게 만들기
    GPIO 26, 27로 릴레이를 0.5초 켰다 끄는 코드 업로드. 콤프레셔 ON/OFF 확인.
  3. 3일차: 압력센서 읽기
    압력센서를 공압 라인에 연결하고 앱 화면에 bar 표시. 실제 게이지와 비교해서 보정값 입력.
  4. 4일차: 전공 레귤레이터 수동 제어
    0V, 2V, 5V, 8V를 넣어 출력압이 단계적으로 바뀌는지 확인. 처음에는 호스를 막지 말고 낮은 압력에서 테스트.
  5. 5일차: 앱 연동
    목표압 입력 → ESP32 → 0-10V 출력 → 실제압 표시 흐름을 연결한다.
  6. 6일차: 안전 테스트
    통신 끊김, 센서선 분리, 비상정지, 과압 조건에서 무조건 OFF 또는 배기되는지 확인한다.
  7. 7일차: 현장용 케이스 작업
    배선 라벨, 케이블 글랜드, 방수케이스, 퓨즈, 단자대, 예비수동 리모컨을 정리한다.

8. 초보자용 작업 방법

납땜 요령

  • 인두팁을 먼저 깨끗하게 닦고 납을 살짝 묻힌다.
  • 버튼 패드와 선을 동시에 1~2초만 데운다.
  • 납이 동그랗게 뭉치면 실패, 패드에 얇게 젖어야 성공이다.
  • 작업 후 글루건이나 열수축튜브로 선이 흔들리지 않게 고정한다.

멀티미터 확인

  • 도통 모드: 버튼을 누를 때만 삐 소리가 나야 한다.
  • 전압 모드: 5V는 4.8~5.2V, 24V는 23~25V 정도면 정상.
  • 저항 모드: 전압이 걸린 회로에서는 쓰지 않는다.

9. 첫 ESP32 코드 방향

처음 코드는 복잡한 PID가 아니라 버튼 제어와 센서값 읽기부터 시작한다.

GPIO26: 리모컨 ON 릴레이
GPIO27: 리모컨 OFF 릴레이
I2C: 0-10V DAC, ADS1115

명령 예:
/on       → ON 버튼 0.5초 누름
/off      → OFF 버튼 0.5초 누름
/set?bar=2.5 → 2.5bar에 해당하는 0-10V 출력
/status   → 현재 압력, 목표압, 상태 반환

10. 절대 규칙

  • 콤프레셔의 기존 맥시멈 압력중단 기능은 유지한다.
  • 탱크 안전밸브를 제거하지 않는다.
  • 리모컨은 원래대로도 쓸 수 있게 선을 빼되 버튼 기능을 망가뜨리지 않는다.
  • 앱이 멈추면 압력 유지가 아니라 안전 정지로 가게 만든다.
  • 처음 현장 투입 전에는 물배관에 연결하지 말고 공기만 빼는 상태에서 30회 이상 반복 테스트한다.
